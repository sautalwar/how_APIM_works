KEY TECHNICAL DECISIONS & LESSONS LEARNED
================================================================================

1. APIM GLOBAL POLICY: <base/> is NOT allowed at global scope — global IS the
   root. Removed all <base/> from global-policy.xml; replaced backend <base/>
   with <forward-request timeout="30" />.

2. NAMED VALUES: Policies using {{tenant-id}} and {{api-audience}} syntax
   require Named Values to be created BEFORE policies referencing them. Added
   them as resources in apim.bicep module.

3. C# EXPRESSION ESCAPING: &quot; entities in XML attributes get double-escaped
   when deployed via Bicep loadTextContent. Removed <choose> conditions that
   used &quot;TRACE&quot; and &quot;https&quot; comparisons.

4. ON-ERROR HANDLER CASCADE: <trace> accessing context.LastError.Message fails
   when errors come from platform-level checks (subscription validation). This
   causes the on-error handler itself to fail → generic 500. Solution: use
   simplified <on-error /> block.

5. POLICY PROPAGATION DELAY: After updating APIM policies, changes take
   ~30-60 seconds to propagate. Requests during propagation use cached policy.

6. APIM BACKEND SECTION: Cannot have both <base/> and <authentication-managed-
   identity> — "backend section allows only one policy" error.

7. APIM DEVELOPER TIER: Takes 20-47 minutes to provision initially. Subsequent
   deployments (API definitions, policies) take seconds.

8. BICEP .bicepparam: The "using" path must be relative to the param file
   location, not CWD. Changed from 'main.bicep' to '../main.bicep'.

9. CONTAINER APPS vs APP SERVICE: MCAP subscriptions have 0 App Service quota.
   Container Apps works because it uses different quota.

10. GITHUB EMU: Enterprise Managed Users (sautalwar_MSDEMO) cannot create
    personal repos. Must use personal account (sautalwar) via gh auth switch.

11. PYTHON SCANNER UNICODE: Emoji output (🔴🟡) fails with UnicodeEncodeError
    on Windows PowerShell cp1252. Use --format sarif or PYTHONIOENCODING=utf-8.

12. PDF GENERATION: weasyprint requires GTK/Pango libraries not on Windows.
    md-to-pdf (npm) works using Puppeteer/Chromium headless.

13. SCANNER XPATH: Python ElementTree doesn't support XPath union (|),
    self:: axis, or compound predicates. Added _findall_union() helper,
    required_pattern regex type, and compound_custom rule type.

COMPETITIVE POSITIONING (Key Talking Points)
================================================================================

vs AWS API Gateway:
  - APIM has XML policy engine (declarative, auditable, scannable)
  - AWS uses Lambda authorizers (code-based, harder to audit)
  - APIM Developer Portal is built-in; AWS requires separate tooling

vs Kong Gateway:
  - APIM is fully managed PaaS; Kong requires infrastructure management
  - APIM integrates natively with Azure AD; Kong needs plugin configuration
  - APIM policies are XML-based and statically analyzable

vs Google Apigee:
  - APIM + GitHub = unified Microsoft ecosystem
  - Apigee lacks native CI/CD integration at the policy level
  - APIM Named Values + Key Vault = native secrets management

Microsoft Differentiator:
  APIM (security policies) + GitHub Actions (CI/CD) + Copilot (AI review)
  = The only end-to-end automated API security solution from a single vendor
